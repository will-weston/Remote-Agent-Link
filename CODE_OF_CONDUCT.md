# Community conduct

Be respectful, constructive, and welcoming. Critique code and ideas, not people.
Harassment, threats, discriminatory abuse, doxxing, and sharing private
information without permission are not acceptable.

Keep discussions relevant, respect consent and privacy, and do not pressure
contributors to grant desktop access, publish credentials, or run unsafe
reproductions. These expectations apply to issues, pull requests, reviews and
other project spaces.

Maintainers may edit or remove inappropriate content, limit participation, or
block accounts to protect the community. Apply these expectations consistently.
For abuse on GitHub, use GitHub's private **Report abuse** controls. For a
moderation question, contact a maintainer without repeating sensitive details
publicly. Technical vulnerabilities follow [SECURITY.md](SECURITY.md), not a
public conduct discussion.
